# Student Performance Analysis

A Python-based project that analyses student academic performance using data analysis, visualisation, and machine learning.

The project examines subject-wise marks, attendance, and assessment trends to identify student strengths and areas for improvement. It also uses Linear Regression, Decision Tree, and Random Forest models to predict final examination scores.

**Key Features:**
- Student performance analysis and visualisation.
- Subject-wise and department-wise comparisons.
- Machine learning model training and evaluation.
- Student score cards and progress reports.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn, Google Colab.
